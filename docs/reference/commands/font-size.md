# @font.size

以降のテキストのフォントサイズを変更します。

## 構文

```
@font.size <サイズ>
@font.size
```

パラメータを省略するとフォントサイズがリセットされます。

## パラメータ

| パラメータ | 説明 |
| --- | --- |
| `サイズ` | CSS の `font-size` に有効な値。省略した場合はリセット。 |

## 使用例

```
@font.size 2em
大きなテキスト
@font.size
通常のテキストに戻る
```

```
@font.size 24px
@font.size 1.5rem
@font.size larger
```

### インライン記法

テキストの途中でサイズを変えたい場合は、インライン記法を使用します。

```
通常の文字{@font.size 2em}大きい文字{@font.size}通常の文字
```

## 注意

`@font.size` で設定したサイズは、`@page` を実行してもリセットされません。次のページでも元に戻したい場合は、明示的に `@font.size` を呼び出してください。

## 戻り値

なし
