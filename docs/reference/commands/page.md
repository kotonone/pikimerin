# @page

テキストコンテナの内容をすべてクリアします。

## 構文

```
@page
```

## 説明

`@page` はテキストコンテナに描画されたすべてのテキストを消去します。新しい場面へ切り替わる際に使用します。

```
1ページ目のテキストです。

2ページ目のテキストです。
```

## 自動挿入

スクリプト中に **2行以上の空行** または **フォームフィード文字 (`\f`)** が現れると、パーサーが自動で `@page` を挿入します。

```
1ページ目

2ページ目
```

上記は内部的に以下と同等です。

```
@text 1ページ目
@pause
@page
@text 2ページ目
@pause
```

## 戻り値

なし
