# @sleep

指定した時間だけスクリプトの進行を停止します。

## 構文

```
@sleep <時間>
```

## パラメータ

| パラメータ | 説明 |
| --- | --- |
| `時間` | 停止する時間。単位付き文字列または数値（秒）を指定します。 |

### 時間の指定方法

数値のみを指定した場合は**秒**として扱われます。単位付きの文字列も使用できます。

| 書式 | 単位 | 例 |
| --- | --- | --- |
| `<数値>` | 秒 | `@sleep 2` |
| `<数値> ms` / `msec` / `millisecond(s)` | ミリ秒 | `@sleep 500ms` |
| `<数値> s` / `sec` / `second(s)` | 秒 | `@sleep 2s` |
| `<数値> m` / `min` / `minute(s)` | 分 | `@sleep 1m` |
| `<数値> h` / `hr` / `hour(s)` | 時間 | `@sleep 1h` |
| `<数値> d` / `day(s)` | 日 | `@sleep 1d` |

## 使用例

```
効果音や演出の後、少し間を置く。
@sleep 1.5s
次の台詞へ。
```

```
@sleep 500ms
```

## 戻り値

指定した時間が経過した後に解決される[非同期処理](../asynchronous) `AbortablePromise<void>` を返します。
